# Fajji Restaurant Website

Welcome to the **Fajji Restaurant Website** repository! This project is a complete modern redesign of a casual luxury Italian dining website, tailored to provide a premium, interactive, and visually stunning user experience.

## ✨ Features

* **Elegant Seagreen & Gold Theme:** A rich, high-contrast visual design that screams luxury while remaining highly readable.
* **Glassmorphism UI:** Menu cards and the reservation form feature translucent "frosted glass" effects that blend beautifully with the background.
* **Interactive 3D Menu Cards:** Hovering your mouse over the menu items creates a real-time, smooth 3D tilt effect driven by Vanilla JavaScript math.
* **Dynamic Navigation Bar:** The transparent navbar seamlessly transitions into a sleek, dark-themed solid bar as you scroll down the page, ensuring text always stays visible.
* **Functional Reservation System:** A beautiful booking form with interactive focus states, Chrome autofill support, and an elegant simulated "Success" message animation.
* **Fully Responsive:** Beautifully crafted layouts that adapt perfectly to mobile, tablet, and desktop screens.

## 🛠️ Technology Stack

* **HTML5:** Semantic and accessible structure.
* **CSS3:** Advanced styling using CSS Variables, Flexbox, CSS Grid, `backdrop-filter`, and CSS Animations/Keyframes.
* **Vanilla JavaScript (ES6+):** Lightweight script for handling scroll events, 3D mouse tracking calculations, and form submission logic without relying on heavy frameworks.

## 🚀 How to Run Locally

You don't need any complex build steps or dependencies to run this project! 

1. **Clone or Download** this repository to your local machine.
2. **Open** the `index.html` file directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   * *Optional:* For the best development experience, you can serve it via a local development server like VS Code's Live Server or using `npx http-server`.
3. Enjoy the luxury dining experience!
